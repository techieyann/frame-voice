# Release notes

Current defaults are **right X** for Clear and a **white tray microphone**
(white crossed-out microphone when disabled). Blue/red headset feedback is
separate from tray status.

- [v0.1.1: white tray icons and X Clear default](releases/v0.1.1.md)
- [v0.1.0: initial stable release](releases/v0.1.0.md)

Installers and update checks select the latest stable release. Existing saved
button choices are preserved; use Controllers to change an older B binding to X.
