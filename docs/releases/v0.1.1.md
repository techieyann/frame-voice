# Frame Voice v0.1.1

- The tray uses a white microphone with the Frame corner mark. Disabled dictation uses the same white icon with its existing cross. Headset recording/cancellation colours are unchanged.
- New installations use right-controller **X** for Clear, matching left D-pad Left. This avoids B's native Desktop space. Existing configured button choices are retained; select X in Controllers to change them.
- Default X clears exactly the tracked dictation and its separator, without an extra controller Backspace. Optional native-space handling applies only when B is explicitly selected.
- User docs now separate settings, troubleshooting, removal, and developer references, with a configuration screenshot and a concise transcription comparison.

Updates preserve saved settings, API keys, and downloaded models. Open Configure → General → Check for updates.
